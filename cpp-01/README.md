# cpp-01 — Memory & References

Where the C++ memory model becomes tangible. This module covers the difference between stack and heap allocation, when to use a pointer vs. a reference, and how member function pointers work under the hood.

<br>

## Exercises

- **ex00 — BraiiiiiiinnnzzzZ** — Stack vs. heap allocation through a `Zombie` class.
- **ex01 — Moar brainz!** — Allocating a horde of zombies as a single contiguous array.
- **ex02 — HI THIS IS BRAIN** — Pointers vs. references on the same data.
- **ex03 — Unnecessary violence** — A `HumanA` / `HumanB` pair: reference members vs. pointer members.
- **ex04 — Sed is for losers** — A small file-based find-and-replace tool using `std::string`.
- **ex05 — Harl 2.0** — Routing string inputs to member functions via an array of pointers-to-members.
- **ex06 — Harl filter** — Adding the `switch` statement to filter Harl's complaints by level.

<br>

## Concepts Covered

- `new` / `delete` and `new[]` / `delete[]`
- Pointers vs. references: when each is the right tool
- Reference members and why they cannot be reseated
- Pointers to member functions
- The `switch` statement
- Reading from and writing to files with `std::ifstream` / `std::ofstream`
