# cpp-00 — Getting Started with C++

The starting point. This module introduces the building blocks of a C++ program — how classes are declared and defined, how data flows through the standard streams, and the difference between stack-allocated and statically-bound members.

<br>

## Exercises

- **ex00 — Megaphone** — Take command-line arguments and shout them back in upper case via `std::cout`. A first taste of `std::string` and stream I/O.
- **ex01 — PhoneBook** — A small in-memory contact book. Practice classes, member functions, encapsulation, fixed-size arrays, and well-formatted tabular output.

<br>

## Concepts Covered

- Namespaces and the `std` namespace
- Class declaration vs. definition
- Member functions and access specifiers
- `std::cin` / `std::cout` / `std::cerr`
- Initialization lists
- `static` and `const` qualifiers

<br>

## Build & Run

```sh
cd ex00 && make && ./megaphone "hi"
```
